# csql motion

**Part of [customer-success-skills](../../#readme), CS Pulse's open library of AI skills for the work customer success actually does.**

Designs how customer success generates and hands off qualified expansion leads without damaging the relationship that produced them. It opens by forcing a decision most programmes never make explicitly - should CS spot-and-handoff, own expansion end to end, or do neither because the trust is worth more unmonetised - because a hybrid where CSMs are expected to sell but are neither trained nor paid for it is the default, and the worst of the three.

Qualification has to be behavioural or stated, never felt: a seat count hitting a limit, a named owner with a stated need, an explicit "can we do this for the other division too" - because "they seem happy" produces volume with no conversion, and that is how these programmes get quietly cancelled. The handoff itself is designed as an introduction rather than a transfer: the CSM stays in the room, context is read before contact, and there is no cold outreach to a warm account, ever. The failure this exists to prevent: **the lead dropped into a queue** - the first badly handled handoff teaches the CS team that flagging an opportunity gets their customer called by someone who has not read anything, and the flow of signals stops within a month.

Part of the **Lead the function** group in this library.

## Who this is for

For CS leaders and managers running the function itself, not a single account.

## What this needs

Works with nothing but what you want CS to spot and who would work it. Gets better with historical expansion data, and both teams' compensation plans.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it names the checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the csql-motion skill from
https://github.com/CSPulse/customer-success-skills/tree/main/skills/csql-motion,
zip the csql-motion folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/csql-motion`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.
