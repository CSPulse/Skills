# coaching

**Part of [customer-success-skills](../../#readme), CS Pulse's open library of AI skills for the work customer success actually does.**

Runs the one-to-one, the call review, and the development conversation so behavior changes instead of just getting described. Most call reviews are accurate and change nothing: the person hears an honest account of what happened, agrees with it, and does the same thing next time.

Before coaching anything, it diagnoses whether the real problem is skill, knowledge, will, or environment. Four problems that wear the same clothes, but need completely different responses. Coaching an environment problem, telling someone a structural failure is their personal deficiency, is the most damaging misdiagnosis available. Once the diagnosis is right, it picks one observable behavior, asks for the person's own self-assessment first, gives feedback about the moment rather than the person, and rehearses the behavior out loud instead of just explaining it. It closes by agreeing what gets observed next and when, because coaching with no follow-up is a conversation with a nice feeling attached and nothing else.

The failure this exists to prevent: **the list of six things.** Comprehensive, fair, accurate, and impossible to act on. A list of six improvements is a list of zero.

Part of the **Lead the function** group in this library.

## Who this is for

For CS leaders and managers running the function itself, not a single account.

## What this needs

Works with nothing but something you observed yourself. Gets better with the recording or artefact, and a pattern across several observations.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it names the checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the coaching skill from
https://github.com/CSPulse/customer-success-skills/tree/main/skills/coaching,
zip the coaching folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/coaching`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.
