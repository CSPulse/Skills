# business review

**Part of [customer-success-skills](../../#readme), CS Pulse's open library of AI skills for the work customer success actually does.**

Starts by checking whether the review should happen at all - not when there's a live unresolved escalation (a value review while the customer is angry reads as tone-deaf), not when there's no baseline to measure against, not when the decision-maker won't be in the room and reaching them was the point, and not on autopilot quarterly cadence when nothing has actually changed since last time. Once it's worth running, everything gets built from one sentence written before a single data point is gathered: what does this customer need to walk away believing. The value case is then built to a standard finance would accept - a ladder from activity (logins, tickets: appendix material at best) through outcome (cycle time, error rate, in the customer's own units) up to business impact (money or risk), each number carrying its baseline, its full cost including the customer's own time, and an attribution assumption stated out loud rather than smuggled in, so the number survives being forwarded to their CFO instead of dying the moment someone tries to rebuild the arithmetic.

The failure this exists to prevent: **fifty-five slides of usage data when the customer asked for four charts** - activity presented and called value, because it's the easiest thing to pull from a dashboard and the least convincing thing in the room. The rest of the mechanism protects the meeting itself: pre-briefing the champion so they're never surprised in front of their own executive, sequencing the customer's business first instead of a company update, holding to three to five themes with roughly a third presentation and two thirds discussion, and closing with an explicit ask - because an expansion conversation disguised as a value review is what customers actually punish, not the upsell itself.

Part of the **Run the set-piece** group in this library.

## Who this is for

For CSMs running the big, mostly one-shot moments in an account's lifecycle, the ones with no redo if they go wrong.

## What this needs

Works with nothing but the account and the date. Gets better with their stated goals, outcome data, the attendee list.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it names the checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the business-review skill from
https://github.com/CSPulse/customer-success-skills/tree/main/skills/business-review,
zip the business-review folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/business-review`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.
