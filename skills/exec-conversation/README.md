# exec conversation

**Part of [customer-success-skills](../../#readme), CS Pulse's open library of 32 AI skills for the work customer success actually does.**

Prepares fifteen minutes with someone three levels up who has no context and did not ask for the meeting. One ask, one number they recognise, and the two questions only they can answer.

Part of the **Handle the conversation** group in this library.

## Who this is for

For anyone who has to walk into a customer conversation prepared, or walk out of one with the follow-through actually captured.

## What this needs

Works with nothing but their title and why the meeting exists. Gets better with ten minutes with the champion, outcome data in their measure.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it names the checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the exec-conversation skill from https://github.com/CSPulse/customer-success-skills/tree/main/skills/exec-conversation, zip the exec-conversation folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/exec-conversation`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.
