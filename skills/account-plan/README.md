# account plan

**Part of [customer-success-skills](../../#readme), CS Pulse's open library of AI skills for the work customer success actually does.**

Writes the durable twelve-month account plan against one test: could someone inheriting this account in month four read it and know what was promised, by whom, and what is supposed to be true by when. If not, it's a status report with an ambitious heading. It states the objective in the customer's own words with a baseline and a named owner on their side - not "drive adoption," which is your goal about their behavior, but the outcome they'd recognize as theirs - caps the action list at three to five items because more than that means nothing is prioritized, and gives every risk a trigger and a response instead of leaving it as a worry ("champion may leave" becomes "champion is interviewing, which we'd see as a slowed reply pattern; if that happens we accelerate the introduction to their VP").

The failure this exists to prevent: **the plan full of activity** - twelve initiatives, no measure, no owner on the customer's side, nothing that can be failed and therefore nothing that is ever actually achieved. It also draws a line this library takes seriously: `account-context` is the business-wide substrate written once, `onboarding-plan` covers the first ninety days, and this is the durable per-account picture that succeeds it - not every account earns one, and writing a full plan for all forty in a book is how the format stops being trusted.

Part of the **Run the book** group in this library.

## Who this is for

For CSMs managing more accounts than they can give equal attention to, and being honest about the tradeoffs that forces.

## What this needs

Works with nothing but the account, its contract, and what you know of their goals. Gets better with the original business case, outcome data, a stakeholder map.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it names the checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the account-plan skill from
https://github.com/CSPulse/customer-success-skills/tree/main/skills/account-plan,
zip the account-plan folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/account-plan`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.
