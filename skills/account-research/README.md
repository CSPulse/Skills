# account research

**Part of [customer-success-skills](../../#readme), CS Pulse's open library of 32 AI skills for the work customer success actually does.**

Archaeology on an account you inherited: what was sold, by whom, on what promise, and which of it nobody has questioned since. Marks every claim as documented, reported or folklore, and ends with the questions it could not answer.

Part of the **Read the account** group in this library.

## Who this is for

For CSMs and account managers who need an honest read on an account, whether it is one they have run for years or one they just inherited.

## What this needs

Works with nothing but the account name and whatever you were handed. Gets better with the original deal notes, the mailbox, twenty minutes with whoever had it before.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it names the checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the account-research skill from https://github.com/CSPulse/customer-success-skills/tree/main/skills/account-research, zip the account-research folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/account-research`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.
